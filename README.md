Desktop application for managing assets and an investment portfolio,
built with C++/CLI and Windows Forms.

## About the project

A university coursework project demonstrating work with:
- Investment portfolio management
- Investor management
- Optimization strategies
- Generating recommendations

## Features

- Viewing portfolio and assets
- Generation of market scenarios
- Optimization strategies
- Recommendation generation

## Technologies

- **Language:** C++/CLI (.NET)
- **UI:** Windows Forms
- **IDE:** Visual Studio 2022
- **VCS:** Git
